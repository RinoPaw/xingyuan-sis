星原 GUI 字体资源

MFLiHei_Noncommercial-Regular.otf
  随包附带的原始字库文件，未修改字形或内部名称。
  Tk 字体族：MFLiHeiNoncommercial。

BarlowCondensed-Black.ttf
  Barlow Condensed Black。来源：Google Fonts 的 Barlow Condensed 目录。
  https://github.com/google/fonts/tree/main/ofl/barlowcondensed
  原始许可证见 Barlow-OFL.txt。

Windows 使用 AddFontResourceExW / FR_PRIVATE 在当前进程加载。
退出时释放，不写入系统字体目录或注册表。正文使用已安装的中文字体。
其他平台暂使用已安装字体及系统后备字体。

本版未包含 Tungsten 或汉仪尚巍荒野，也未使用 AI 图片。
