# 演示数据来源

`src/xingyuan_sis/seed_data.py` 中的数据只用于课程设计、界面演示和测试，不代表真实学校、学生或作品官方设定。

## 学生筛选原则

当前 seed 只保留有明确作品来源的角色。**年龄不作为入学条件，也不作为删除角色的条件**：普通成年人、年长角色、长寿种和神兽都可以作为星原大学的演示学生。

年龄与出生资料按“知道多少就记录多少”处理，不再为了得到一个完整日期而反推或虚构出生年份：

- 明确知道完整出生日期时记录 `YYYY-MM-DD`，年龄由界面实时计算，不重复保存手动年龄；
- 只知道出生年份时记录 `YYYY`；
- 只知道生日月日时记录 `--MM-DD`；
- 作品明确给出年龄、剧情年龄或较稳定的年龄范围时，可以单独记录 `age`；范围可取其中一个合理演示值；
- 两者都没有足够资料时保持为空。

入学年份、学院、专业和班级与角色生理年龄完全解耦，按演示规则独立分配。神兽或长寿种不会因为年龄被固定到某个年级。

角色姓名字段只记录作品中的正式名、稳定常用名或明确的角色称呼。物种、职位、剧情身份等描述不临时拼进姓名。若某个称呼本身就是作品稳定使用的角色名或专名（如“大先生”、`Fox McCloud`、`Wolf O'Donnell`），则原样保留；中文译名不稳定时宁可保留可靠的原文名，也不自造译名。

## 物种枚举

`SPECIES_FAMILIES` 与 `SPECIES_BRANCHES` 不维护独立固定表，而是从当前 `STUDENTS` 自动生成。因此删除角色后，无人使用的族系 / 支系会自动从演示物种枚举中消失；新增角色的物种也会自动进入枚举。

当前物种分类是为了数据库字段做的归一化，不等同于各作品的官方生物分类学表。

## 其他演示字段

下列字段仍由星原 SIS 自行构造或按固定规则生成，并非来源作品设定：

- 学号、入学年份、学院、专业、班级；
- 学籍状态；
- 主元素与亲和等级；
- 联系方式、宿舍、备注；
- 课程、选课关系与成绩。

学院、专业、班级、课程编号、课程名称、学分和课时均为项目自己的演示设计。每名学生默认生成 4 条选课记录，因此当前 113 名学生对应 **452 条选课 / 成绩记录**。

这些作品名称和角色仅用于非商业课程项目的测试数据。星原 SIS 与上述作品及其权利方不存在官方关联。
