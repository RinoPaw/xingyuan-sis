# 演示数据来源

`src/xingyuan_sis/seed_data.py` 中的数据只用于课程设计、界面演示和测试，不代表真实学校、学生或作品官方设定。

## 学生数据

当前演示库包含 100 名学生。

其中 `_BASE_STUDENTS` 的 12 名学生为本项目自行构造的测试角色；姓名、物种、性别及其余档案字段均为演示数据。

其余 88 名学生使用已有拟人 / furry 作品中的角色作为姓名、物种和性别的参考。当前来源如下：

- **BEASTARS**：雷格西、春、路易、茱诺、杰克、比尔、里兹、刚兵、皮纳、席拉、米古诺、青叶。

除上述 **姓名、物种与性别参考** 外，角色对应的以下学生字段均由本项目自行构造或按规则生成，并非来源作品中的人物设定：

- 学号；
- 出生日期与入学年份；
- 学院、专业和班级；
- 学籍状态；
- 主元素与亲和等级；

- 宿舍；
- 备注。

## 教务结构与课程

学院、专业、班级、课程编号、课程名称、学分和课时均为本项目为 SIS 演示自行设计的数据，不对应真实院校培养方案，也不作为上述作品的设定。

其中“元素学”“元素工程”“元素现象导论”“元素场分析”等名称属于星原 SIS 演示世界观中的课程设计。

## 选课与成绩

学生与课程之间的选课关系由 `seed_data.py` 根据专业课程池自动分配；每名学生默认生成 4 条选课记录。

成绩同样由固定规则生成，用于覆盖“已评分”“待录入”“低分”等界面与查询场景。休学或保留学籍学生的成绩可为空。这些成绩与来源作品中的角色经历没有关系。

## 使用说明

这些作品名称和角色仅作为非商业课程项目中的测试数据来源说明。星原 SIS 与上述作品及其权利方不存在官方关联；若后续将项目用于公开演示之外的正式场景，应考虑将这些角色替换为完全原创或随机生成的数据。
