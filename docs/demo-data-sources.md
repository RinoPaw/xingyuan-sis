# 演示数据来源

`src/xingyuan_sis/seed_data.py` 中的数据只用于课程设计、界面演示和测试，不代表真实学校、学生或作品官方设定。

## 学生筛选原则

当前 seed 只保留有明确作品来源的角色，并按项目偏好排除兔科角色。**年龄不再作为入学条件，也不作为删除角色的条件**：普通成年人、年长角色、长寿种和神兽都可以作为星原大学的演示学生。

年龄只是角色资料。能可靠确认具体年龄时尽量保留；只有年龄范围时，可在来源给出的范围内选取一个演示值；无法可靠确认年龄时保持为空，不为了凑数据虚构年龄。能确认生日月日时尽量保留；只有年龄没有生日时，代码可使用 `01-01` 作为计算年龄的占位日期，该日期不是官方生日。若年龄无法可靠换算成数据库可表示的出生日期，则 `birth_date` 保持为空。

入学年份、学院、专业和班级与角色生理年龄完全解耦，按演示规则独立分配。神兽或长寿种不会因为年龄被固定到某个年级。

## 《家有大猫》物种说明

本项目按角色的兽人 / 神灵形态记录物种，而不是按其附身对象或“神明”这一身份分类：

- 林虎：`猫科 / 虎`；
- 李克劳：`猫科 / 云豹`；
- 猫妖（颜书齐）：`猫科 / 石虎`。

其中李克劳是鲁凯族云豹神灵；猫妖以石虎形态出现并附身颜书齐。年龄若没有足够可靠的原作依据则保持为空。

## 物种枚举

`SPECIES_FAMILIES` 与 `SPECIES_BRANCHES` 不维护独立固定表，而是从当前 `STUDENTS` 自动生成。因此删除角色后，无人使用的族系 / 支系会自动从演示物种枚举中消失；新增角色的物种也会自动进入枚举。

当前物种分类是为了数据库字段做的归一化，不等同于各作品的官方生物分类学表。

## 其他演示字段

下列字段仍由星原 SIS 自行构造或按固定规则生成，并非来源作品设定：

- 学号、入学年份、学院、专业、班级；
- 学籍状态；
- 主元素与亲和等级；
- 联系方式、宿舍、备注；
- 课程、选课关系与成绩。

学院、专业、班级、课程编号、课程名称、学分和课时均为项目自己的演示设计。每名学生默认生成 4 条选课记录，因此当前 88 名学生对应 **352 条选课 / 成绩记录**。

这些作品名称和角色仅用于非商业课程项目的测试数据。星原 SIS 与上述作品及其权利方不存在官方关联。
