# 演示数据来源

`src/xingyuan_sis/seed_data.py` 中的数据只用于课程设计、界面演示和测试，不代表真实学校、学生或作品官方设定。

## 学生筛选原则

当前 seed 只保留有明确作品来源、且年龄适合作为大学生演示数据的角色。项目自行构造的 12 名学生已经删除；来源明确但年龄低于 18 岁、高于 25 岁，或无法较可靠确认年龄的角色也不再进入 seed。

年龄统一以 `2026-09-15` 作为演示世界的参考日期。作品能提供月日时，`birth_date` 尽量保留该生日；只能够确认年龄、无法确认完整生日时，代码使用 `01-01` 作为计算年龄的占位日期。这个占位日期不是作品官方生日。

入学年份根据演示年龄重新分配：18 岁为 2026 级、19 岁为 2025 级、20 岁为 2024 级，21～25 岁归入 2023 级。学院、专业、班级、学籍、主元素、亲和、联系方式、宿舍和备注仍为星原 SIS 的演示数据。

## 物种数据

`SPECIES_FAMILIES` 与 `SPECIES_BRANCHES` 不再维护一份独立的固定枚举，而是从当前 `STUDENTS` 自动生成。因此删除学生后，没有任何保留角色使用的族系 / 支系也会自动从演示物种枚举中消失。

当前物种分类是为数据库字段做的归一化，不等同于作品官方分类。此次同步修正了部分较粗的旧值，例如：

- 春：`兔科 / 荷兰侏儒兔`；
- 席拉：`猫科 / 猎豹`；
- Chase Hunter：`鼬科 / 北美河獭`。

## 其他演示字段

下列数据仍由项目自行构造或按固定规则生成，不来自角色原作：

- 学号、入学年份、学院、专业、班级；
- 学籍状态；
- 主元素与亲和等级；
- 联系方式、宿舍、备注；
- 课程、选课关系与成绩。

学院、专业、班级、课程编号、课程名称、学分和课时均为星原 SIS 的演示设计。每名学生默认生成 4 条选课记录，因此当前 33 名学生对应 **132 条选课 / 成绩记录**。

这些作品名称和角色仅用于非商业课程项目的测试数据。星原 SIS 与上述作品及其权利方不存在官方关联。
