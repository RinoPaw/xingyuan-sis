# 星原静态视觉 · 第二版

2026-10-22：本版替代上一版的保守布局。P5R 参考用于整页构图、比例与黑白红关系；移除“红色只能用于主操作”的规则。

设计先决：
- 红色舞台贯穿整个窗口；黑白章节签错位排列，脱离封闭侧栏。
- 名册是黑底名录与白色档案的并置；当前人物姓名在档案成为最大的文字。
- 公告采用窄目录、宽正文；成绩采用上方成绩凭条与下方通栏列表。
- 登录以几何兽形校徽和大比例校名建立学校身份；正文表单保持水平可读。
- 形状保留矢量坐标；Tk 9 内置 SVG 在当前物理尺寸抗锯齿重绘，缩放不放大旧像素图。无 AI 生成图片。控件保留原生键盘、菜单与业务接口。
- 每个页面标题只出现一次，没有装饰英文和 slogan。

参考：[P5R 主菜单](https://hanbagu.hatenadiary.jp/entry/2022/12/11/083000)、[开发者讲座](https://www.famitsu.com/news/201711/13145540.html)。后者讲的是 P5 的设计方法，不能误称 P5R 专属访谈。
