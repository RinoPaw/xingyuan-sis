# Terminal UI 设计规范

本文档定义星原 SIS 交互式终端界面的视觉层级与样式语义。样式应按“信息角色”选择，避免因为组件位置相近就复用同一种颜色。

## 1. 视觉层级

从高到低：

1. **当前页面标题 / 当前导航项**：强调色 + 粗体。用于用户当前所在位置，例如 `01 / 学生档案`、当前选中的 `1 学生`。
2. **区块标题**：主文字色 + 粗体。用于区块名称，例如 `校园概览`、`档案字段`。区块标题不能与下面的字段标签使用同一视觉样式。
3. **关键值**：强调色 + 粗体。用于需要快速扫读的数字或状态值，例如学生总数 `100`。
4. **普通正文 / 普通导航项**：终端默认主文字层级，不额外强调。
5. **字段标签 / 说明文字 / 面包屑中的次要层级**：弱化文字色。
6. **结构分隔符**：只承担布局作用，不应比字段标签更抢眼。

原则：**颜色表达语义层级，不表达“这是某个组件”。** 同一层级保持一致，不同层级必须有可见差异。

## 2. 颜色与表面

当前 256 色基准：

| 角色 | 样式 | 用途 |
| --- | --- | --- |
| 页面背景 | xterm 235 (`#262626`) | 主工作区 |
| 顶栏背景 | xterm 234 | 顶部应用栏 |
| 底栏背景 | xterm 236 | 底部操作栏 |
| 普通按钮背景 | xterm 237 | 可点击按钮 |
| 选中背景 | xterm 238 | 选中按钮/高亮行 |
| 主文字 | xterm 252 | 正文、区块标题 |
| 弱化文字 | xterm 245 | 字段标签、说明文字、次级导航信息 |
| 主强调色 | xterm 110 | 当前页面、当前导航项、关键值 |
| 金色强调 | xterm 180 | 首页轨道动画 |

不要修改宿主终端客户端的背景色；应用只负责自身绘制区域。

## 3. 标题与字段

页面标题使用主强调色 + 粗体；区块标题使用主文字色 + 粗体；字段标签使用弱化文字色；字段值根据重要性使用普通主文字或强调色。

例如首页左侧应形成以下层级：

```text
首页                 ← 次级位置提示
▌ 1 学生             ← 当前导航项，强调色 + 粗体
  2 教务             ← 普通导航项
...

校园概览             ← 区块标题，主文字色 + 粗体
学生 100   班级 26   ← 标签弱化；关键数字强调
课程 20    选课 400
```

`校园概览` 与 `学生 / 班级 / 课程 / 选课` 不得使用相同颜色和字重。

## 4. 强调色使用范围

强调色数量应克制。优先用于：当前页面标题、当前导航项、关键统计值、明确的交互焦点。说明文字、字段标签、区块标题不应全部使用强调色，否则层级会被抹平。

## 5. 布局原则

宽屏首页采用左侧导航 + 右侧主视觉；左侧统计区属于导航下方的辅助信息，不与导航项争夺视觉焦点。底部只保留一条操作栏。结构分隔线应弱于正文。

窄屏允许重新排布，但视觉语义保持不变：页面标题仍高于区块标题，区块标题仍高于字段标签。

## 6. 实现约束

样式 token 集中定义，避免在布局代码中散落临时 ANSI 色号。新增样式时先确定其语义角色，再决定色号；如果现有 token 已能表达该角色，应复用现有 token。

任何视觉调整如果改变了标题、正文、标签、选中态或关键值之间的层级关系，应同步更新本文档。
