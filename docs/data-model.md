## 设计原则

- 避免把所有信息都堆进学生表。
- 可重复出现或会随时间变化的数据优先独立建表。
- 数据库中可以保存完整信息，但 TUI 默认只展示必要内容。
- 学号、课程编号等业务标识需要考虑唯一约束。
